### JWT and Refresh Tokens

<div style="width: 90%;">
<h2>Purposes of JWT and Refresh Tokens</h2>
<p style="width: 90%;">
With JWT, security can be strengthened in stateless services.
An expiration date can be set to authentication in a properties file.
Refresh Tokens are used to ensure higher security.</p>

<h2>Mechanism of JWT and Refresh Token</h2>
<p>
JWT is typically generated by hashing user data (e.g. username) 
with the secret key that's stored in the server and a specific algorythm. 
In this application, HmacSHA256 is used.</p>

<p>
When the user logs in, the REST API generates JWT and a refresh token, and both are set to the response cookie.  Subsequent requests will always contain JWT in their cookie, and when the requests demand access to the resources that require authentication, the security filter verifies the JWT.  If JWT is valid, the request will be handled normally, and otherwise an error response will be returned to the client.</p>
<p>
If JWT has expired, a custom status code of 420 will be returned to the client.
When the client receives this status code, it requests the server to regenerate a JWT,
and in this case the request will include the refresh token.</p>
<p>
The server verifies the refresh token, and if it is valid, it issues a new JWT and returns it.
If the refresh token has expired, the user will be logged out, and an error response will be sent. If the user will have to log in again in order to access resources that require authentication.</p>
<p>
In this application, expiration of JWT is set to 10 minutes and that of refresh token is set to 24 hours.</p>

#### 上記処理を定義するクラス
<p style="width: 90%;">
- AuthTokenFilter.java
パッケージ：com.restapi.ecommerce.security.jwt
メソッドdoFilterInternalで、リクエストのクッキーからJWTを抽出、検証し、有効であれば、
UserDetailsServiceのメソッドloadUserByUsernameよりユーザ情報を取得し、
権限などのデータをセキュリティコンテキストに設定する。

- AuthEntryPointJwt.java
パッケージ：com.restapi.ecommerce.security.jwt
フィルターチェーンで例外が発生した際のレスポンス設定処理を定義している。
エラーレスポンスがCORSを回避してフロントエンドに届くようヘッダに下記を設定。
  Access-Control-Allow-Credentials: true
  Access-Control-Allow-Origin: (フロントエンドURL)

JWTの有効期限切れで例外が発生した際はカスタムステータス420を設定する。
そのほかの場合はステータス401 Unauthorizedを設定する。

- WebSecurityConfig.java
パッケージ：com.restapi.ecommerce.security
UsernamePasswordAuthenticationFilterの前にAuthTokenFilterを挿入している。</p>
